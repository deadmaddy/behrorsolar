# Security Policy

## Supported version

Security fixes are applied to the current version of BehrorSolar.in
and the latest code on this repository’s main branch.

Older revisions are not maintained separately.

## Reporting a vulnerability

If you discover a security vulnerability affecting this repository
or https://behrorsolar.in/, please report it privately to:

**myadav@behrorsolar.in**

Subject: **Security report — Behror Solar**

Please include:

- The affected URL or file.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Screenshots or a minimal proof of concept, where helpful.

Do not include passwords, access tokens or personal customer data.

Please do not disclose vulnerability details in public GitHub issues,
discussions or pull requests before we have reviewed the report and
had an opportunity to address it.

## Responsible testing

Keep testing limited to what is necessary to demonstrate the issue.
Do not access or modify other people’s data, disrupt the website,
submit bulk enquiries or perform denial-of-service testing.

Third-party services linked from the website are outside this
repository’s scope. Report vulnerabilities in those services to
their respective providers.

## Review process

We will review reports and communicate with the reporter about
findings and any required fixes.

This project does not currently offer a paid bug bounty programme.
